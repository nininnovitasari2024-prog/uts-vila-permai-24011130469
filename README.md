## Deskripsi Singkat Fitur
Aplikasi web interaktif untuk pemesanan akomodasi Vila Permai yang dilengkapi dengan fitur daftar vila berbasis array objek, pencarian otomatis, validasi formulir pemesanan, perhitungan harga otomatis, penyimpanan sesi dengan localStorage, dan navigasi Single Page Application (SPA).

## Cara Menjalankan
1. Pastikan seluruh file (`index.html`, `style.css`, `script.js`) berada dalam satu folder yang sama (`uts-vila-permai`).
2. Buka file **`index.html`** menggunakan browser web (seperti Google Chrome atau Microsoft Edge).
